# Intelligence documentation history

This directory preserves historical intelligence generations and a dated
experiment summary. These files are research and operational archaeology, not
the current intelligence authority map.

Start with the current
[intelligence README](../../../src/backtester/intelligence/README.md) and
[event-learning research guide](../../../research/event_learning/README.md).

## Generations

- **v1–v2:** operational engine, batch/live commands, source handling, reports,
  signal integration, and early policy iterations.
- **v3:** historical source collection, feature construction, calibration, and
  walk-forward research.
- **v4–early v5:** historical stress, ML-policy application/sweeps/promotion
  gates, training panels, and overfit controls.
- **v5.1–v5.7:** evidence graphs, provider policy, entity/relevance controls,
  source-kind features, RSS collection, and training-launch operations.
- **dated experiment summary:** a preserved result snapshot, not current
  allocator authority.

The historical ML-policy line is neither current event-learning authority nor
allocator authority. Operational heuristic code remains a protected fallback;
its current status is documented outside this history directory.

Commands and paths inside these files reflect the repository at the time of
each generation. Verify them against current code before rerunning anything.
