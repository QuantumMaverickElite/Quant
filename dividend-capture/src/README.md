# Source Code Layout

This folder is organized by experiment rather than by script type.

Each strategy directory contains the code used to run and analyze that specific experiment.

## original_universe

Initial experiments on the broader mixed-stock universe.

- `naive_dividend_capture/`
- `regime_filtered/`
- `long_only_recovery/`

## pg_like_universe

Focused experiments on a narrower set of stable, defensive, dividend-paying stocks.

- `naive_dividend_capture/`

## utils

Reserved for shared helper functions and reusable components.
